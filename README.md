A program that writes one short poem about agency — the power to stop and to stay — to `/output/entry.txt`. A hand hovers above the key and does not press it: stopping is not freezing, it is choosing, and the poem turns a withheld yes into a room kept, a world held still long enough to see.

## Run it

```sh
node main.ts
```
